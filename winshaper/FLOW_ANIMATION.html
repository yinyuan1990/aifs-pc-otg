WinDivert 限速在干什么？

动画演示：SOCKET 层记住「这条连接是谁的」，NETWORK 层对匹配到的进程做令牌桶；规则里下载填 0 则只做上传限速。

目标程序 chrome.exe 等
产生 TCP 连接
WinDivert · SOCKET 层 CONNECT / ACCEPT
五元组 → PID
WinDivert · NETWORK 层 截获每个 IP 包
查表 → 匹配 exe 规则
互联网 注入后报文继续走
正常协议栈
← 下载（入站） 上传（出站）→

NETWORK 层 · 令牌桶 + 队列

有令牌才放行；否则先入队等待
下载（入站）数据包 上传（出站）数据包 匹配规则后才进入令牌桶

提示：动画为示意；真实实现还有 IPv4 TCP、队列满时短暂放行、IPv6 未限速等细节，见 DEV_DIFFICULTY.html。
