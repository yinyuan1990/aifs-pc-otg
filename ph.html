🎬 帧率平滑算法 - 完整数学模型

Phoenix 应用层 Jitter Buffer + 自适应消费 + 渐进式延迟调整

📐 核心数学公式
1. 指数移动平均 (EMA)
X(t) = α × Xraw + (1 - α) × X(t-1)
α 越小越平滑，响应越慢；α 越大响应越快但波动大
2. 到达速率估计
R(t) = 0.3 × Rraw + 0.7 × R(t-1)
Rraw = 当前秒实际到达帧数，支持 5-60fps 任意帧率
3. 缓冲深度平滑
D(t) = 0.2 × Draw + 0.8 × D(t-1)
β=0.2 非常平滑，避免深度波动导致间隔跳变
4. 自适应消费间隔
Ibase = 1000 / R(t)
E(t) = Target - D(t)
Iraw = Ibase + Kp × E(t)
I(t) = 0.3 × Iraw + 0.7 × I(t-1)
Kp=2.0 比例补偿系数，误差越大调整越快
📊 算法参数表
参数符号值含义
到达率EMA系数α0.3响应较快，跟踪帧率变化
深度EMA系数β0.2非常平滑，避免跳变
间隔EMA系数γ0.3渐变过渡，丝滑体验
比例补偿系数Kp2.0误差放大倍数
最大加速倍率-1.3x温和追赶，防快进
最大减速倍率-0.5x等待帧到来
降级确认时间-10秒网络稳定才降延迟
5. 动态范围限制
Imin = Ibase / 1.3 (最快1.3倍速)
Imax = Ibase / 0.5 (最慢0.5倍速)
Ifinal = clamp(I(t), Imin, Imax)
自动适应 5-60fps 任意帧率
