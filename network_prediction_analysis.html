🔮 网络波动预测方案 - 如何提前知道网络恶化

核心问题：能否在网络真正恶化前 提前感知并预降帧？

✅ 结论先行

答案是：可以！ 通过以下方法可以提前 500ms ~ 2s 预测网络恶化：
  • 抖动趋势分析：抖动在上升 → 网络正在恶化
  • 到达率斜率：到达率快速下降 → 网络即将恶化
  • 队列下降速度：队列每秒下降 ≥ 3帧 → 提前降帧
  • RTT 趋势：RTT 持续上升 → 拥塞正在加剧
传统"被动式"方案的问题：
  • 等到队列 < 3帧才降帧 → 已经来不及，用户已经卡了
  • 等到丢包 > 5% 才反应 → 已经丢了很多帧
  • 等到延迟 > 200ms 才处理 → 体验已经差了

🎯 五大预测指标（核心）

1️⃣ 抖动趋势（Jitter Trend）⭐最敏感

原理：网络恶化时，最先表现为帧间隔不稳定（抖动上升），比丢包/队列变化更早。
抖动变化率 = (当前抖动EMA - 1秒前抖动EMA) / 1秒

示例（60fps，期望间隔 16.7ms）：
- 1秒前抖动EMA = 2ms（抖动比例 12%）
- 当前抖动EMA = 5ms（抖动比例 30%）
- 抖动变化率 = (5 - 2) / 1 = +3ms/秒 → 网络正在恶化！
抖动变化率 含义 动作
≤ 0 抖动稳定或下降 ✅ 可升帧
0 ~ 2ms/秒 轻微上升 📊 观察
> 2ms/秒 快速上升 ⚠️ 预警降帧
> 5ms/秒 急剧上升 🛑 立即降帧

2️⃣ 到达率斜率（Arrival Rate Slope）⭐实用

原理：不只看当前到达率是多少，还要看它下降多快。
到达率斜率 = (当前到达率 - 1秒前到达率) / 1秒

示例：
- 1秒前到达率 = 98%
- 当前到达率 = 85%
- 斜率 = (0.85 - 0.98) / 1 = -13%/秒 → 网络快速恶化！
到达率斜率 含义 动作
≥ 0 到达率稳定或上升 ✅ 可升帧
-5% ~ 0 轻微下降 📊 观察
-10% ~ -5% 明显下降 ⚠️ 预警降帧
< -10% 急剧下降 🛑 立即降帧

3️⃣ 队列下降速度（Queue Drop Speed）⭐你们已有

原理：队列快速下降意味着"入不敷出"，即将见底。
队列下降速度 = 1秒前队列 - 当前队列

示例（60fps）：
- 1秒前队列 = 9帧
- 当前队列 = 5帧
- 下降速度 = 9 - 5 = 4帧/秒 → 预计 1.25秒后见底！
下降速度 预计见底时间 动作
≤ 0（队列在增加） - ✅ 可升帧
1-2帧/秒 3-5秒 📊 观察
≥ 3帧/秒 1-2秒 ⚠️ 预警降帧
≥ 5帧/秒 < 1秒 🛑 立即降帧

4️⃣ RTT 趋势（RTT Trend）

原理：RTT 持续上升表示网络拥塞正在加剧。
RTT 变化率 = (当前RTT - 1秒前RTT) / 1秒

示例：
- 1秒前 RTT = 50ms
- 当前 RTT = 120ms
- 变化率 = (120 - 50) / 1 = +70ms/秒 → 拥塞加剧！
RTT 变化率 含义 动作
≤ 0 RTT 稳定或下降 ✅ 网络恢复
0 ~ 30ms/秒 轻微上升 📊 观察
> 50ms/秒 快速上升 ⚠️ 预警降帧
> 100ms/秒 急剧上升 🛑 立即降帧

5️⃣ 丢包突增检测（Loss Spike）

原理：连续多个采样周期丢包率上升，说明网络正在恶化。
丢包趋势 = 连续 N 次丢包率都在上升

示例：
- T-2: 丢包率 1%
- T-1: 丢包率 3%
- T-0: 丢包率 5%
- 连续 3 次上升 → 网络恶化趋势确认！

📐 综合预测公式

网络恶化风险分 = W1×抖动变化率 + W2×到达率斜率 + W3×队列下降速度 + W4×RTT变化率

建议权重：
- W1 = 0.30（抖动变化率，最敏感）
- W2 = 0.25（到达率斜率）
- W3 = 0.25（队列下降速度）
- W4 = 0.20（RTT变化率）

风险分阈值：
- < 0.3：正常
- 0.3 ~ 0.5：预警，准备降帧
- 0.5 ~ 0.7：降一档
- > 0.7：紧急降到最低档
简化版（推荐先用这个）：
满足以下任意两个即触发预警降帧：
  • 抖动变化率 > 2ms/秒
  • 到达率斜率 < -5%/秒
  • 队列下降速度 ≥ 3帧/秒
  • RTT 变化率 > 50ms/秒

💻 C++ 实现：网络趋势预测器

// network_trend_predictor.h
#pragma once

#include <deque>
#include <chrono>

namespace adaptive {

struct TrendMetrics {
    double jitterTrend;      // 抖动变化率 (ms/s)
    double arrivalSlope;     // 到达率斜率 (%/s)
    int    queueDropSpeed;   // 队列下降速度 (帧/s)
    double rttTrend;         // RTT变化率 (ms/s)
    double riskScore;        // 综合风险分 (0~1)
    bool   isPredictDrop;    // 是否预测需要降帧
};

class NetworkTrendPredictor {
public:
    NetworkTrendPredictor();
    
    // 更新指标历史
    void update(double jitterEma, double arrivalRate, int queueDepth, int rttMs);
    
    // 获取趋势预测结果
    TrendMetrics getTrend() const;
    
    // 是否需要预警降帧
    bool shouldPreemptiveDrop() const;

private:
    struct Sample {
        int64_t timestamp;
        double jitterEma;
        double arrivalRate;
        int queueDepth;
        int rttMs;
    };
    
    std::deque<Sample> m_history;
    static constexpr size_t HISTORY_SIZE = 5;  // 保留5秒历史
    
    // 阈值
    static constexpr double JITTER_TREND_THRESHOLD = 2.0;   // ms/s
    static constexpr double ARRIVAL_SLOPE_THRESHOLD = -0.05; // -5%/s
    static constexpr int    QUEUE_DROP_THRESHOLD = 3;        // 帧/s
    static constexpr double RTT_TREND_THRESHOLD = 50.0;      // ms/s
};

} // namespace adaptive

// network_trend_predictor.cpp
#include "network_trend_predictor.h"
#include <algorithm>
#include <cmath>

namespace adaptive {

NetworkTrendPredictor::NetworkTrendPredictor() {}

void NetworkTrendPredictor::update(double jitterEma, double arrivalRate, int queueDepth, int rttMs) {
    auto now = std::chrono::duration_cast<std::chrono::milliseconds>(
        std::chrono::steady_clock::now().time_since_epoch()).count();
    
    m_history.push_back({now, jitterEma, arrivalRate, queueDepth, rttMs});
    
    // 只保留最近 HISTORY_SIZE 秒
    while (m_history.size() > HISTORY_SIZE) {
        m_history.pop_front();
    }
}

TrendMetrics NetworkTrendPredictor::getTrend() const {
    TrendMetrics trend = {0, 0, 0, 0, 0, false};
    
    if (m_history.size() < 2) {
        return trend;
    }
    
    // 取最新和 1 秒前的样本比较
    const auto& current = m_history.back();
    const auto& previous = m_history.front();
    
    double timeDelta = (current.timestamp - previous.timestamp) / 1000.0;  // 秒
    if (timeDelta <= 0) {
        return trend;
    }
    
    // ===== 计算各项趋势 =====
    
    // 1. 抖动趋势
    trend.jitterTrend = (current.jitterEma - previous.jitterEma) / timeDelta;
    
    // 2. 到达率斜率
    trend.arrivalSlope = (current.arrivalRate - previous.arrivalRate) / timeDelta;
    
    // 3. 队列下降速度
    trend.queueDropSpeed = (int)((previous.queueDepth - current.queueDepth) / timeDelta);
    
    // 4. RTT 趋势
    trend.rttTrend = (current.rttMs - previous.rttMs) / timeDelta;
    
    // ===== 计算风险分 =====
    double jitterScore = std::max(0.0, trend.jitterTrend / 10.0);           // 10ms/s → 1.0
    double arrivalScore = std::max(0.0, -trend.arrivalSlope / 0.2);         // -20%/s → 1.0
    double queueScore = std::max(0.0, trend.queueDropSpeed / 6.0);          // 6帧/s → 1.0
    double rttScore = std::max(0.0, trend.rttTrend / 200.0);                // 200ms/s → 1.0
    
    trend.riskScore = 0.30 * jitterScore + 0.25 * arrivalScore + 
                      0.25 * queueScore + 0.20 * rttScore;
    trend.riskScore = std::min(1.0, trend.riskScore);
    
    // ===== 判断是否预警 =====
    int warningCount = 0;
    if (trend.jitterTrend > JITTER_TREND_THRESHOLD) warningCount++;
    if (trend.arrivalSlope < ARRIVAL_SLOPE_THRESHOLD) warningCount++;
    if (trend.queueDropSpeed >= QUEUE_DROP_THRESHOLD) warningCount++;
    if (trend.rttTrend > RTT_TREND_THRESHOLD) warningCount++;
    
    // 满足 2 个或以上条件，或风险分 > 0.5
    trend.isPredictDrop = (warningCount >= 2) || (trend.riskScore > 0.5);
    
    return trend;
}

bool NetworkTrendPredictor::shouldPreemptiveDrop() const {
    return getTrend().isPredictDrop;
}

} // namespace adaptive

✅ 总结

核心答案：能否提前知道网络波动？

能！通过监测以下趋势指标，可以提前 500ms ~ 2s 预测：
  1. 抖动趋势：抖动上升 > 2ms/秒 → 网络正在恶化
